# Workflow: final visual audit (step 7)

1. Run `python scripts/cdcheck.py timeline timeline.json`. Errors = fix. Warnings = fix or explain in the report.
2. Walk the checklist (tick each; write the shot ids that fail):
   - [ ] Subject consistency: same person/object looks the same (AI: continuity sheet reused).
   - [ ] Spatial consistency: geography block respected; re-establish after big moves.
   - [ ] Screen direction and eyelines continuous (180°); cuts change >= 30° or one size step.
   - [ ] Camera movement: every move has a motivation and a designed end frame; no moves during text.
   - [ ] Focus continuity: the sharp subject is the one the story needs; racks are motivated.
   - [ ] Lighting continuity: direction, quality, temperature per scene.
   - [ ] Colour: the colour script holds; accent colour only on the core idea.
   - [ ] Objects and props in place.
   - [ ] Transitions have meanings; no decorative effects.
   - [ ] Narrative relevance: every shot has a job in the beat map; nothing reveals before its time.
   - [ ] Restraint: budgets of the mode kept; no repeated sequence pattern.
   - [ ] Adapter: every instruction executable or with a fallback.
   - [ ] User intent unchanged.
3. Write the result in report section 7.
