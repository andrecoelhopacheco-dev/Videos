# Workflow: one scene to a shot list (fast)

Use for a single scene or when the user asks "how do I shoot this?".
1. One-line brief: intent, mode, target.
2. Geography block (`direction/blocking_and_continuity.md`) and the scene's one emotional change.
3. See/hide pair if the scene has a reveal.
4. 3-8 shots as a table: # · size/angle · lens at distance · move + motivation (or static) · focus · duration · reason.
5. One rejected alternative for the key shot.
6. Coverage note (what extra to shoot or render for the edit).
No timeline.json unless timing matters; run `cdcheck.py` if you write one.
