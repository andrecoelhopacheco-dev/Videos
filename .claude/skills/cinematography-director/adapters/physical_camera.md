# Adapter: real camera and crew

Everything is possible in principle; the limits are time, money, space, safety and light. Write instructions a crew can act on without asking.

## Supports and what they give
| Support | Moves | Note |
|---|---|---|
| tripod + fluid head | pan, tilt, static, zoom | authority, precision |

| dolly + track | push, pull, truck, arc (curved track) | smooth, repeatable |
| gimbal | follow, walk-in, low orbit | floating; drift on long takes |
| Steadicam | long follows, stairs, running (S09) | operator skill needed |
| jib / crane / Technocrane | rise, fall, sweeping reveals (S09) | space and crew |
| drone | aerial, crane-like exteriors | rules and permits apply |
| handheld | subjective, documentary | shoulder rig for long takes |

## Technical checks (label TECHNICAL)
- Frame rate and shutter: 24/25 fps at 180° shutter (about 1/48 s at 24 fps, S37); fast pans judder - keep pan speed low. Narrow shutter for staccato action, wide for dreamy smear (S37).
- Focal length equivalence for the actual sensor (crop factor, S34).
- Focus breathing on close racks (S23).
- Exposure for the chosen stop: light to the stop, use ND outdoors for shallow DOF.
- Coverage: master + the sizes the edit needs; overlap action for cut-on-action; room tone and cutaways for documentary.
- Continuity: geography block printed for the crew; script supervisor notes for props.
- Vertical delivery: frame for 9:16 at capture, or shoot 16:9 UHD and remember only 1.125x punch-in headroom in the vertical crop.
