# M06 Educational and technology (tech, cybersecurity, science, AI, tutorials)

Auto-detect: "explain", "how", "tutorial", "lesson", "cyber", "AI", "science", "tech".

## Priorities
1. Visual explanation: each concept becomes literal, process or metaphor (`core/visual_storytelling.md`, 5 routes); metaphors only when they help memory and stay accurate.
2. Concept visualisation: show the mechanism step by step; one step per shot.
3. Information hierarchy: one primary element per frame; supporting labels smaller.
4. Screen compositions: screen recordings and UI are framed, cropped and zoomed to the exact element; never a full desktop at phone size.
5. Motion graphics: diagrams build in the order of the narration.
6. Demonstrations: insert shots of real actions (hands, keyboard, device) to ground abstractions.
7. Technical accuracy: no fake UI or wrong terminal output; a visual metaphor must not teach a wrong model.
8. Clear transitions: one idea ends before the next starts.
9. Narration sync: the visual appears on the word that names it (measured).

## Defaults
| Item | Default |
|---|---|
| Camera | static while reading; zoom (not dolly) into UI details; moves between reading windows |
| DOF | deep for screens and diagrams; shallow only for human/consequence shots (<= 20%) |
| Angles | eye level presenter; overhead for hands-on processes |
| Light | high-key or clean screen-lit; low-key only for threat beats (cyber attacks) |
| Colour | one accent colour = the core concept; danger/attacker colour defined in the colour script |

## Avoid
Hacker clichés (hooded figure, green code rain) unless used knowingly; moving camera over text; decorative 3D that hides the mechanism.
