# Vídeos

Estúdio do Claude para criar **motion graphics** e **editar vídeos**, com saída em **MP4** (toca no iPhone).

- Motion do zero: [Remotion](https://www.remotion.dev) (React → vídeo). Edição: ffmpeg.
- `npm ci` e depois `npm run render -- Exemplo` → `saidas/Exemplo.mp4` + folha de quadros.
- Regras, fluxo e uso econômico de modelos: [`CLAUDE.md`](CLAUDE.md). Gosto do dono: [`docs/estilo.md`](docs/estilo.md).
