# Referências aprovadas

Um arquivo por nicho ou tema (ex.: `nicho-politica.md`, `thumbnails.md`). A skill `pedir-referencias` lê esta
pasta antes de perguntar qualquer coisa e grava aqui o que o dono escolheu, para não perguntar de novo.
Vídeos de referência analisados quadro a quadro ficam em `docs/estudos/`; aqui fica só a decisão.

Formato de cada entrada:

```
## <data> · <pedido em poucas palavras>
- Referências: <vídeo, canal ou link> → <o que tirar dele>
- Antirreferências: <o que evitar>
- Estado: aprovado | provisório (o Claude escolheu sozinho)
```
